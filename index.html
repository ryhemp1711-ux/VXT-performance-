YOUR WORK, ACROSS DEVICES

Cloud sync

Upload your roster, results and predictions, then download them on your other device. Transfers are manual and replace the destination copy; records are not merged automatically.

Use a VXT account on both devices. Your Supabase dashboard login is separate. New accounts may need email confirmation.

Signing out leaves downloaded records on this device.

Recovery copy

Before a replacement, the previous destination copy is kept in this browser. Export it here and restore it through Data & backup if needed. Each replacement updates this recovery copy.

One-time setup for the app owner

Run the database setup SQL in Supabase’s SQL Editor. Then set Authentication → URL Configuration → Site URL to this app’s address. Add that address to Redirect URLs too.

Import season records from a screenshot

Choose one screenshot at a time. Images are read on this device; the first scan needs internet to load the reader. Review all detected values before saving.

Season records keep their year when the exact race date is unknown. Timing defaults to Unknown. Wind and indoor/outdoor labels are kept in notes. These records can affect your personal bests; review wind and timing before using them.

PRACTICE LOG

Log a group training session

Save multiple athletes and reps together: continuous runs, sled pushes, wicket runs, and broken runs. Only continuous run times and splits feed race results and matching predictor inputs.

Add athletes in Overview first. Enter cumulative times from the same start: for example, 10m 1.99, 20m 3.22, 30m 4.38, finish 60m 7.88. Flying efforts have a separate event choice.

Saved sessions

Successful saves open below. Drill and broken-run details stay in the session; they are not continuous race results. Edit continuous run times in Results. Rest is shown in seconds.
