YOUR WORK, ACROSS DEVICES

Cloud sync

Upload your roster, results and predictions, then download them on your other device. Transfers are manual and replace the destination copy; records are not merged automatically.

Use a VXT account on both devices. Your Supabase dashboard login is separate. New accounts may need email confirmation.

Signing out leaves downloaded records on this device.

Recovery copy

Before a replacement, the previous destination copy is kept in this browser. Export it here and restore it through Data & backup if needed. Each replacement updates this recovery copy.

One-time setup for the app owner

Run the database setup SQL in Supabase’s SQL Editor. Then set Authentication → URL Configuration → Site URL to this app’s address. Add that address to Redirect URLs too.

Import season records from a screenshot

Choose one screenshot at a time. Images are read on this device; the first scan needs internet to load the reader. Review all detected values before saving.

PRACTICE LOG

Log a group training session

Save multiple athletes and reps together: continuous runs, sled pushes, wicket runs, broken runs, tempo, and 400 the hard way. Only continuous run times and splits feed race results and matching predictor inputs.

Replace the current session draft with this planned workout?

Add athletes in Overview first. Enter cumulative times from the same start: for example, 10m 1.99, 20m 3.22, 30m 4.38, finish 60m 7.88. Flying efforts have a separate event choice.

Scheduling conflicts

Same-day sessions and assigned block date ranges are checked regardless of start time. Logging a planned workout may require Include anyway. Reps within this session are allowed.

    Saved sessions

    Successful saves open below. Drill and broken-run details stay in the session; they are not continuous race results. Edit continuous run times in Results. Rest is shown in seconds.

    TRAINING PLAN

    Create a training block

    Plan 3, 6, 9, 12 weeks or longer in three-week increments. Each week has a focus and space for workouts, target times and recovery. Plans do not create completed results.

    Assign athletes (optional)

    Leave unchecked for a general team plan.

    Saved training blocks

    Open a block to review or edit it. Blocks are included in JSON backups and manual cloud transfers.

    ONE WORKOUT, MULTIPLE ATHLETES

    Assign a team workout

    Write the shared workout once and select its athletes. Each athlete starts as planned; mark completion separately below. Log measured results in Training sessions.

    Loading a template replaces the shared prescription fields. Targets and readiness are entered per athlete after assignment.

    Result-entry defaults

    These create blank rep entries when you log this workout. Drill details and measured times are entered during logging; written instructions are not automatically parsed.

    Assign athletes

    Scheduling conflicts

    These athletes have an assigned block covering this date or another team workout or saved session on the same date. A block overlap does not necessarily mean a workout is planned that day. Unassigned general blocks are not treated as athlete assignments.

      Assigned team workouts

      Edits apply to every assigned athlete. Changing the shared workout or date resets completion. Workouts remain available after reload and in backups.

      Your training week

      Start times are local. Block ranges may include rest days. Linked results are shown within their planned workout; other same-day assignments appear as possible conflicts.

      Training groups

      Save rosters such as youth, short sprinters, and long sprinters. Adding a group selects its current athletes; later group edits do not change existing assignments.

      Group athletes

      Reusable workout templates

      Save a shared prescription and blank rep-entry defaults. Templates never save measured times or create results.

      Practice mode

      Take attendance and enter rep times. Each entry saves as a draft on this device.

      Athlete progress report

      Uses recorded results and check-ins. No readiness score or race projection is invented. Save coach notes before printing or downloading.
